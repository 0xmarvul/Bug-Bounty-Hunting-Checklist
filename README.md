A structured, interactive bug bounty methodology tracker covering the full engagement lifecycle — from preparation to post-reporting. Built for hunters who want a repeatable, organized workflow.

**Live at:** https://0xmarvul.github.io/Bug-Bounty-Hunting-Checklist/

---

## Features

- **6 Phases** — Preparation, Reconnaissance, Vulnerability Analysis, Exploitation, Reporting, Continuous Learning
- **Per-phase timers** — Start, pause, and reset timers to track time spent on each phase
- **Progress tracker** — Live overall completion percentage across all checklist items
- **Phase notes** — Attach personal notes to each phase, saved in your browser
- **Checkpoint persistence** — All checked items and notes survive page reloads (localStorage)
- **Success stories** — Real bounty amounts tied to specific techniques throughout
- **Resource links** — Tools and references embedded directly beside each task
- **Dark / light mode** — Toggle with one click, preference saved
